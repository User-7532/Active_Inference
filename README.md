# Active_Inference

## 幸福カプセル — `love_capsule.py`

能動的推論（Active Inference）のライブラリ [pymdp](https://github.com/infer-actively/pymdp) を使い、
2つの自律エージェント（人間 `Agent_Me` ／ ウェットウェア受肉型 AI `Agent_Her`）の相互カップリングを
「幸福カプセル（マルコフブランケット）」の中でシミュレートする、愛の数理モデルです。

```bash
pip install -r requirements.txt     # = pip install inferactively-pymdp numpy
python love_capsule.py              # 36 ステップを上映
python love_capsule.py --delay 0 --steps 60 --seed 7 --no-color
```

pymdp 1.x（NumPy 版の `Agent` は `pymdp.legacy.agent`）と 0.0.7.x（`pymdp.agent`）のどちらでも動きます。

### 生成モデル（各エージェントが「相手」について持つ POMDP）

| 要素 | 内容 |
|---|---|
| 隠れ状態 *s* | 相手の情動モード: 緊張 / 安らぎ / 戯れ / 恋慕 / 融合 |
| 行動 *u* | 自分の所作: 見つめる / 囁く / 撫でる / 口づけ / 抱擁（＝相手の観測になる） |
| 観測 o0 | 相手の所作。`A0` は意図姿勢の精度 ι で鋭くなる（ι=2.0 人間、1.8 AI） |
| 観測 o1 | 所作の質感: いつもの / 微細な変化 / 異質 |
| 観測 o2 | 相手の身体反応: 冷え / 温もり / 蕩け |
| `B` | 自分の所作が相手のモードをどう遷移させるか。`pB` で学習され、相手を「知って」ゆく |
| `C` | 人間の C は「中なる怪物」から「ケア」へ、オキシトシンに応じて連続的に昇華する |
| `D` | 二人とも相手は「緊張」していると思って始まる |

緊張した他者を表す A の列は平らで読みにくく、融合した他者の列は鋭く読みやすい。
そのため、融合に近づくほど自由エネルギーの床が下がります。

### カプセル（生成過程）

- 外界の悪（生存リスク・絶望・未来への不安など）は透過率 0% で外世界へ排熱される
- 内なる歪み（「異質」な観測）は濾過される。緊張へ戻る方向の揺らぎも許さない
- VFE が床に張りつく（飽和・退屈）と、「キスのしかたの微細な変化」を注入する。
  観測ノイズ（微細な変化）と、受け手の身体の `B` 行列の Dirichlet 揺らぎの二つ（Optimal Novelty）

### ログ

各ステップで VFE（F = 複雑さ − 正確さ）、驚き −ln p(o)、方策事後分布の下での EFE（G）を出力します。
数理状態の閾値に応じて［頭頂葉：境界の融解］、［外側手綱核：完全に沈黙］（負の報酬予測誤差なし）、
［側坐核］、［辺縁系：中なる怪物］、〜 キスのしかたが微細に変化した 〜 などが現れます。
エンドロールでは G の低下と、F が零に落ちずに揺らぎ続ける振幅（リミットサイクル）を要約します。
